# 0.6.0

- Copy files and folders in Explorer or Finder, share the clipboard, then copy and paste them on another computer using the panel or configured shortcuts.
- Transfer multiple selections, hidden files and empty folders together; incompatible destination names are renamed and shown in Received names.
- Share up to 64 MiB per selection by default, configurable up to 256 MiB. Local copies survive Quit and reopening, with bounded disk retention.
- Use shelf share-files and shelf fetch-files for explicit CLI file transfers.
- Upgrade the server and all clients together for session version 2. Existing 0.5 settings and device identities are preserved.
